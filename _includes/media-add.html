Connect to GitHub

Saving commits the entry straight to the {{ site.media_repo }} repo, so this browser needs a GitHub token. It is kept in this browser only.

  1. Open GitHub → new fine-grained token.
  2. Under Repository access, pick Only select repositories and choose {{ site.media_repo | split: '/' | last }}.
  3. Under Permissions, set Contents to Read and write.
  4. Generate it and paste it here.
